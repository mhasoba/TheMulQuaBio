# Performance, Scaling, and Compute

Use these pages when a sound algorithm and correct implementation still need
more careful profiling, memory management or computing resources. If you are
deciding how to formulate the problem—or why algorithms matter in the first
place—begin with [Algorithms: solving problems with
computation](../notebooks/algorithms).

Performance is one consideration when choosing an algorithm, not the whole
subject. A method may also be valuable because it makes reasoning clearer,
supports reliable tests or allows a previously inaccessible scientific problem
to be addressed.

Knuth's warning about premature optimisation is useful here: do not begin by
polishing whichever line happens to look slow. Establish correctness, measure
the relevant work, and then decide whether the algorithm, its implementation or
the available hardware is actually limiting you.
